# Product

## Register

product

## Users
Primary users are retail traders and independent researchers who run single-ticker and batch analyses to understand a stock before acting. Secondary users are technical operators who tune providers, model choices, and runtime settings to keep analysis quality and system stability high.

Users typically work in short decision windows where they need clear run status, fast access to evidence, and enough control to adjust configuration without leaving the workflow.

## Product Purpose
TradingAgents provides an operational command center for running, monitoring, and reviewing multi-agent market analysis. It turns a complex research pipeline into an actionable flow: configure, run, inspect artifacts, and decide next steps.

Success means users can complete an analysis loop with high confidence in what happened, why the rating was produced, and what to do next, without hunting across multiple tools.

## Brand Personality
Approachable, guided, and competent.

Voice and tone should reduce cognitive load for non-expert users while preserving technical trust for advanced users. The interface should feel calm and clear under uncertainty, with explicit status language and practical next actions.

## Anti-references
- Generic glossy SaaS marketing aesthetics that prioritize decoration over utility.
- Neon trading-terminal visuals that increase urgency and fatigue.
- Dense enterprise backoffice complexity with overloaded controls and jargon-heavy labels.
- Playful consumer-app styling that weakens financial-research credibility.

## Design Principles
1. Guide first, expose depth progressively. Keep essential actions obvious and move advanced controls behind clear disclosures.
2. Make system state legible at a glance. Users should always know run status, progress, and failure context without digging.
3. Keep evidence close to decisions. Present ratings, confidence, and report context in one continuous flow.
4. Optimize for repeatable workflows. Favor consistency across dashboard, history, screener, and system views so frequent users build speed.
5. Prefer clarity over spectacle. Visual design supports trust, readability, and decision quality, not novelty.

## Accessibility & Inclusion
Current baseline is best-effort accessibility with practical safeguards:
- Maintain readable contrast and typographic hierarchy on all primary surfaces.
- Preserve keyboard-reachable controls for core run and review flows.
- Respect reduced-motion user preferences where motion is used.

The next formal milestone should be upgrading this baseline to WCAG 2.1 AA across critical flows.
