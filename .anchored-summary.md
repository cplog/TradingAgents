# TradingAgents — Anchored Summary

## Goal

Integrate free data sources and platform features from PanWatch into TradingAgents for US/HK markets.

## Constraints & Preferences

- No A-share-specific features — focus on US and HK markets only
- All new data sources must be free, no API key required where possible
- Must follow existing TradingAgents architecture (VENDOR_METHODS, fallback chain, error taxonomy)
- MIT license — code can be directly adapted with attribution (PanWatch)

## Key Decisions

- K-Line Context is a pure utility (not a vendor-routed tool) — agents import and call it directly on OHLCV data they've already fetched
- Notifier extension reuses existing Apprise delivery for dingtalk/lark/pushover/bark (Apprise-native), and implements custom async `httpx` senders for wecom/serverchan/pushplus (channels Apprise doesn't support natively)
- Price Alerts use yfinance directly for real-time quotes (rather than `route_to_vendor("get_stock_data")` which returns historical CSV only)
- Price Alert Engine follows the existing `MonitorEngine` pattern (singleton, `start()`/`stop()` asyncio loop, JSON state persistence)

## Critical Context

- **`backend_url` overrides persist in state store (Cloudflare D1)** — setting via `POST /admin/runtime-config` or `POST /admin/persisted-secrets` survives restarts. A stale `backend_url` (e.g. NVIDIA's URL left from a previous run) silently overrides the provider's native endpoint, causing 404s when provider and model don't match the backend. To clear: `POST /admin/runtime-config {"backend_url": ""}`.
- **Nemotron 550B is too slow for 180s LLM timeout** — use `TRADINGAGENTS_LLM_TIMEOUT_SECONDS=600` or switch to smaller NVIDIA models (e.g. `nvidia/llama-3.1-nemotron-nano-8b-v1`).
- **Notifications globally disabled by default** — must be set to `enabled: true` via config/UI before `send()` works.
- `tradingagents/dataflows/kline_context.py` exports `compute_kline_context()`, `compute_kline_context_from_df()`, `compute_kline_context_from_csv()`
- `api/notifications.py` now routes channel types: Apprise-native (`_APPRISE_TYPES`: telegram, bark, dingtalk, lark, discord, pushover), custom HTTP (`_CUSTOM_TYPES`: wecom, serverchan, pushplus), JSON webhook fallback (webhook, slack, email)
- 2 pre-existing test failures in `tests/test_data_vendor_routing.py` (AlphaVantageNotConfiguredError inherits from ValueError — unrelated)
- All 5 notification tests pass; price alert engine smoke tests pass
